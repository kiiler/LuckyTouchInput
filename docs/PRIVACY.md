# Privacy

Lucky Touch Input is local-only.

- No network requests, accounts, telemetry, advertising, or update checks.
- No typed keys, inserted text, prompt text, or clipboard contents are written to logs.
- Session snippets remain in memory and disappear when the process exits.
- Diagnostics contain only timestamps, operation names, exception types, and exception messages.
- Settings and diagnostics are stored under `%LOCALAPPDATA%\Lucky\TouchInput`.
