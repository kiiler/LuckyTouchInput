# 紧凑悬浮键盘：需求与验收

状态：实验功能。2026-10-14，首个便携测试版获得一位用户的手机远控初步验证。
该结论不代表所有输入法、远控软件、DPI 或手机均已验证。

## 问题与目标

手机横屏远控 Windows 时，底部全宽键盘使手指需要横跨屏幕。
用户希望键盘像手机悬浮输入面板一样靠近一侧，并能按握持方式调整位置和大小。
本次目标是验证触达与布局，不是实现九宫格或新的中文输入引擎。

## 第一版范围

| ID | 需求 | 验收条件 |
| --- | --- | --- |
| R1 | 初次打开靠右居中 | 默认 520×360，距工作区右边 16 像素；小屏自动限制在工作区内 |
| R2 | 顶部专用拖动区 | 拖动后位置保持，定时刷新不弹回；普通按键不拖动窗口 |
| R3 | 用户调整宽高 | 右下角手柄自由调整；＋／−调整尺寸；正常工作区最小 400×280 |
| R4 | 位置和尺寸持久化 | 拖动或缩放结束后保存；退出再开恢复；损坏配置回到默认值 |
| R5 | 应对显示器变化 | 保存显示器和工作区；分辨率变化按剩余空间比例映射位置；断开显示器后恢复到可用工作区 |
| R6 | 收起、展开和换边 | 收起为 76×48 按钮；展开恢复原矩形；⇄切换左右侧；托盘可重置 |
| R7 | 紧凑按键布局 | 四行字母页；退格常驻；数字符号、工具切页；单次 Shift/Ctrl |
| R8 | 保持目标输入框 | 点击键盘不激活键盘；英文、数字、退格正确进入目标；不调整应用窗口大小 |
| R9 | 与原版隔离 | 独立 EXE、互斥量、窗口标题、配置目录；原版继续可以构建和使用 |
| R10 | 保留系统输入法 | 发送标准按键；候选和组词仍由当前 Windows 输入法负责 |

像素指主机的 DPI 感知坐标，不是手机上的物理尺寸。
默认值仅是试用起点，不能根据主机分辨率推断拇指可达范围。

## 操作约定

- 顶部拖动条移动；右下角 ◢ 缩放；＋／−增减尺寸；⇄换边。
- — 收起；⌨展开；×退出。再次运行同一 EXE 展开现有实例。
- 工具页的“换行”发送 Shift+Enter；“回车”保持普通 Enter 语义。
- 中文候选、语音、联想和手机本地输入法工具栏不包含在紧凑面板内。
- 不自动提交聊天，不读取输入框文字，不记录用户输入。
- 不修改 Windows 触摸键盘设置，不自动设置开机启动，不请求提权。

## 范围之外

九宫格、双侧分体布局、macOS 移植、候选栏嵌入、自有词库、多指捏合、自动避开光标、
管理员窗口与 UAC 安全桌面、远控客户端改造。鼠标或远控映射的左键拖动是第一版交互基础。

## 验收分层

1. 快速检查：配置往返、越界、小屏、负坐标显示器、三种控制布局尺寸。
2. 独立交互检查：专用文本框内真实鼠标点击、焦点、拖动、缩放、收起、重复按键和保存恢复。
3. 用户验收：手机远控连续输入、按键触达、误触、遮挡、中文选词和退出重开。

首个测试版完成了第 2 层的 165 项检查，并获得用户“初步验证通过”的反馈。
目前没有量化疲劳、误触率、长时间稳定性，也没有完成所有中文候选与多显示器真机组合验证。
集成后的源码验证结果见 [验证记录](COMPACT-VALIDATION.md)。
